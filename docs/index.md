# agrein

**ag** + **rein**, *“a grain”*: two portable contributor workflows for agent-assisted
projects. The MIT plugin ships the same Agent Skills to Codex, Claude Code, and
Antigravity through thin native manifests. Python is used only for contributor
tests and documentation; there is no agrein PyPI package or runtime backend.

Start with native installation, then add the project instruction trigger. The
workflows cover issue and epic ownership, isolated execution, concrete owner
questions, operation approvals, and complete handoffs.

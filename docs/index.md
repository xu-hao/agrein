# agrein

**ag** + **rein**, *“a grain”*: four portable contributor workflows for
agent-assisted projects. The MIT plugin ships the same Agent Skills to Codex,
Claude Code, and Antigravity through thin native manifests. Python is used only
for contributor tests and documentation; there is no agrein PyPI package or
runtime backend.

Start with native installation, then add the project instruction trigger. The
workflows separate single-ticket delivery, multi-ticket epic coordination,
evidence-first bug investigation, and concrete owner escalations.

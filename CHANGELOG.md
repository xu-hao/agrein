# Changelog

## 0.1.0 (2026-11-14)

- Initial MIT release of agrein (ag + rein, *“a grain”*) for Codex, Claude Code,
  and Antigravity using shared Agent Skills discovery.
- Add ticket-and-epic for tracked changes, native epic queues, dedicated workers,
  isolated worktrees, strict contracts, and behavioral verification.
- Add handoff-and-escalation for concrete owner rulings, explicit operation
  approvals, meaningful ticket citations, and four-section handoffs.
- Add contributor packaging tests, read-only native validation, and Sphinx docs.
